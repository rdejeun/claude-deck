Les jauges du forfait proviennent de la status line des sessions CLI (champ rate_limits). L'extension VS Code n'exécute pas de status line : activez la source OAuth ci-dessous si vous l'utilisez seule.

Admin API et solde

Stockée chiffrée (DPAPI) dans votre profil Windows. Utilisée uniquement pour GET /v1/organizations/cost_report.

Aucune API publique ne fournit le solde : saisissez-le après chaque recharge, ClaudeDeck en déduit ensuite la dépense mesurée.

Réglages

Mire de test : chaque touche doit afficher son numéro (1 à 3 en haut), la flèche vers le haut et le carré rouge en haut à gauche. Sinon, ajustez rotation et miroirs.
